# Audio licences — Salon Besties

Story 012. Every sound in the game is **generated at run time** by `src/game/audio.ts` with the Web Audio API, from
the note data in `src/game/config/audio.json`. There are no audio files, samples or third-party recordings, so
nothing here has an outside licence. The music and effects were written for this project (2026-11-10) and belong
to it like the rest of the code.
